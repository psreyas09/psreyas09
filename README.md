## Projects

| Project | What it is | Stack |
| --- | --- | --- |
| **[Sky-Mast](https://github.com/psreyas09/myosa)** | Autonomous crane and structure safety auditor on the MYOSA ESP32 platform. Uses FFT-based vibration analysis, wind estimation, and a relay interlock, with a live OLED dashboard and Bluetooth telemetry. | C/C++, ESP32, MPU6050, BMP180 |
| **IEEE Opportunity Tracker** | Web app tracking 300+ IEEE opportunities in one place, built with IEEE MGA SAC Student Hub. Playwright-based scraping gets around anti-bot blocking. | React, Vite, Node.js, Express, PostgreSQL |
| **[GATE Study Platform](https://github.com/psreyas09/gate)** ([live](https://gatestudy.vercel.app)) | Distraction-free GATE CSE 2027 prep app with lessons and retrieval quick-checks, an SM-2 spaced repetition engine, PYQ practice, and timed mocks with real negative marking. Progress persists in SQLite with backup and export. | React, TypeScript, Vite, Tailwind, Node.js, Express, SQLite |
| **[LyricFlow](https://github.com/psreyas09/lyricsflow)** | Native karaoke-style lyrics companion for Linux. Follows the active MPRIS player, fetches word-synced lyrics from LRCLIB and other sources, shows romanized pronunciation, and works offline. Packaged for Fedora, Debian, and Arch. | Python, PySide6, Qt Quick |
